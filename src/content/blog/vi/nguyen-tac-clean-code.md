Code dễ đọc thường dễ đổi hơn code “khéo” nhưng khó hiểu. Đây là vài nguyên tắc mình hay quay lại khi refactor.

## Đặt tên

Tên nên thể hiện ý định. Nếu cần comment để giải thích tên, hãy cân nhắc đổi tên trước.

## Hàm nhỏ

Hàm làm một việc dễ test và dễ tái sử dụng hơn.
