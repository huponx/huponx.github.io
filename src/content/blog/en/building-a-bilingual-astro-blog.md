This is the first sample post for the blog. The goal is to keep technical notes in a place that is easy to search, easy to share, and simple to maintain.

Astro is a good fit for this because it generates static HTML by default. GitHub Pages can host the generated files without needing a server, which keeps the deployment flow small and predictable.

For bilingual content, each post has its own Markdown file. The English and Vietnamese versions are linked by the same `translationKey`, so the site can show a language switcher when both versions exist.

## What I want to capture here

- Short notes from things I learn.
- Practical setup guides.
- Debugging stories and lessons learned.
- Deeper write-ups about programming, DevOps, databases, and system design.
